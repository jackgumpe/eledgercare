## Stage measurements and uncertainty

`diagnostics.diagnose` first obtains exactly the existing B0/v1 predictions and full scores through unchanged `mapping_v1.scoring.paired`. Expected answers and annotations are used only after predictions, by the diagnostic comparison. They never repair or enter a mapper/model. Original scores are retained as historical metrics; separate records use `eld-coverage-diagnostic/1`.

Visible presence uses NFC and whitespace collapse, case-sensitive exact substring with Unicode word boundaries, within a decoded visible leaf on the correct page. Native page/block/bbox syntax, HTML tags/attributes, comments and script/style content are excluded. Table leaves are decoded cells from successful native parsing; rejected table bodies are not searched. Every hit records block/row/cell, character span, excerpt and leaf digest. Counts include all exact occurrences. Expected same-page value multiplicity is separate. A matching value elsewhere or reused numeric value is not proof of slot identity or semantic association. No edit-distance/fuzzy repair is used.

Primary presence rates require completed output and globally eligible native parsing. Missing/failed/not-run/parse-invalid records retain every expected slot with unavailable presence, not zero error or inferred recognition failure. Locally decoded positive evidence can survive an otherwise ineligible document, but is kept separately without a rate; no-match on incomplete output/parser regions is unavailable. Per-page counts distinguish parsed tables, rejected/unparsed blocks and visible leaves. Parser rejection is observed structure evidence; its downstream recognition implications remain uncertain.

Exact declared field-label support means the frozen label maps to that canonical field ID. Header support requires exact table ID, header sequence and canonical columns. Control support additionally requires both unchanged mappers to recover the ideal native witness; label membership alone is insufficient. See [INTERFACE.md](INTERFACE.md) and `contract.support_control`. Private witness visual fidelity and one-factor isolation require independent admission; an ideal witness is not actual OCR success.

Cell-local evidence uses a unique same-page row key at the annotated canonical index, exact row width and unit spans; it does not borrow another row's correct value. Missing or multiple row matches remain unknown/ambiguous. Field exact-payload evidence retains an explicit unadjudicated relationship flag because global label/value occurrence does not prove geometry/semantic linkage. Unsupported visible vocabulary, unmatched structured slots, nonobserved exact values, reused values, parsing and typed conversion can overlap; counts never form a forced100% causal partition. Exact value not observed can reflect recognition, omission or segmentation, and is labelled ambiguous.

Separate field/cell stage metrics include exact visible payload numerator/eligible denominator/unavailable count; supported-schema numerator/known denominator/unknown count; printed correctness conditioned on supported unique/local exact payload; and typed correctness conditioned on printed exact. Excluded condition members remain counted separately. The conditional association statistic is descriptive evidence, not an intervention-based cause. No document is dropped from original B0/v1 denominators. Literal quantity-unit identity is reported separately from unchanged historical numeric normalization; optional explicit quantity_unit metadata is paired by presence/value. Identifier comparison retains leading zeroes. Explicit blank, unverified/unmapped and nonempty violations remain distinct; zero mapped violation does not prove no invented prose/content.
