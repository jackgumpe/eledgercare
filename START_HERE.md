# Start here

1. Read [AGENTS.md](AGENTS.md) and [CURRENT.md](CURRENT.md).
2. Find only your assignment and exact report reservation in [INDEX.md](INDEX.md).
3. Read the assigned kickoff and verify branch, worktree, full base revision, ownership, and release gates before execution.
4. Use [the reporting guide](docs/agent-reports/README.md) and [template](docs/agent-reports/TEMPLATE.md).

Direction and provenance: [approved direction](docs/coordination/approved-direction.md), [handoff acceptance](docs/coordination/handoff-acceptance.md), and [the supplied kit](docs/inputs/bootstrap-kit/00-START-COORDINATOR.txt).

The seed and coordinator-authored designs are provisional until independently reviewed. Files and roles do not imply a running agent or accepted implementation.
