### Rank 2 — `E2`: Conditional Non-Binarizing Projection-Variance Deskew vs. Uncorrected Raster Pass-Through

- **Lineage:** Reconciled from `Astra H2` (`/001`) and `Carbon H-C3` (`/002`).
- **Source-grounded limitation:** Native `_uocr_build_inputs` (`modeling_unlimitedocr.py` L531–580) resizes/pads pages without rotational correction, so `3°–4°` scanner skew misaligns horizontal invoice/checklist rows across vertical columns and warps horizontal table rules. Unconditional rotation or binarization degrades clean `0.0°` pages.
- **Proposed single treatment (frozen input path, sign convention, & algorithm):** Render each input PDF page via the frozen `pypdfium2==5.15.2` (`PDFium 159.0.8149.0`, `scale=300.0/72.0`) contract (`§2.2`) to obtain deterministic 24-bit RGB buffer $I_{\text{in}}$, and insert **one** deterministic CPU deskew gate ahead of unchanged native `infer_multi(..., crop_mode=False, save_results=False)`. Positive angles denote **counter-clockwise (CCW) rotation in degrees** (`+` = CCW, `-` = CW), matching `PIL.Image.Image.rotate(angle)` and corpus `transform_params.signed_angle_degrees_ccw` ($\theta_{\text{true}} \in \{0.0^\circ, +4.0^\circ, -3.0^\circ\}$):
  1. **Diagnostic foreground mask $M$:** Convert $I_{\text{in}}$ (`W x H` RGB) via `I_in.convert("L")`, compute global Otsu threshold $T \in \{0,\dots,255\}$ maximizing between-class variance $\omega_b(t)\omega_f(t)(\mu_b(t)-\mu_f(t))^2$ (first-maximum tie-break over $t = 0..255$), and construct binary foreground mask $M(y, x) \in \{0, 1\}$ (`1` iff `gray(y, x) <= T`, `0` otherwise) **solely for angle estimation** (never passed to OCR).
  2. **Hypothesized CCW skew $\theta$ and mask leveling operator $M_\theta$:** Evaluate candidate CCW skew angles $\theta \in [-5.0^\circ, +5.0^\circ]$ in exact `0.1°` steps (`101` candidates). For each hypothesized skew $\theta$, level $M$ by rotating CCW by **$-\theta$**:
     $$M_\theta = M.\text{rotate}(-\theta,\; \text{resample}=\text{PIL.Image.Resampling.NEAREST},\; \text{expand}=\text{True},\; \text{fillcolor}=0)$$
     Compute horizontal row sums $S_\theta(y) = \sum_{x=0}^{W_\theta - 1} M_\theta(y, x)$ across expanded height $H_\theta$ and population variance $V(\theta) = \frac{1}{H_\theta}\sum_{y=0}^{H_\theta - 1}\big(S_\theta(y) - \bar{S}_\theta\big)^2$. Select estimated CCW page skew $\hat{\theta} = \arg\max_{\theta} V(\theta)$ with smallest $|\theta|$ first and positive-$\theta$ second tie-break (never reading manifest/expected rotation metadata).
  3. **Gate:** Trigger rotation **if and only if** $|\hat{\theta}| \ge 1.0^\circ$ **and** $V(\hat{\theta}) \ge 1.10 \cdot V(0.0^\circ)$ (`>= 10%` score improvement over `0.0°`).
  4. **No-op invariance:** When untriggered, set applied CCW rotation $\phi_{\text{applied}} = 0.0^\circ$ and pass $I_{\text{in}}$ **byte-for-byte unchanged** (`0` pixel/byte diffs vs. baseline's $I_{\text{in}}$).
  5. **Single resample:** When triggered, set $\phi_{\text{applied}} = -\hat{\theta}$ and rotate original 24-bit RGB buffer $I_{\text{in}}$ **once** via `I_in.rotate(-theta_hat, resample=PIL.Image.Resampling.BILINEAR, expand=True, fillcolor=(255, 255, 255))` (so $+4.0^\circ$ CCW skew yields $\hat{\theta} = +4.0^\circ$, $\phi_{\text{applied}} = -4.0^\circ$, analytic residual $\theta_{\text{res}} = \theta_{\text{true}} + \phi_{\text{applied}} = 0.0^\circ$; $-3.0^\circ$ CW skew yields $\hat{\theta} = -3.0^\circ$, $\phi_{\text{applied}} = +3.0^\circ$, $\theta_{\text{res}} = 0.0^\circ$).
- **Vanilla baseline:** Qualified native `infer_multi(..., crop_mode=False, save_results=False)` consuming the **identical uncorrected pre-gate RGB buffer $I_{\text{in}}$** from the frozen `pypdfium2==5.15.2` (`scale=300.0/72.0`) path (`8` unrotated `v1-raster300` PDFs at `2550 x 3301` px and `8` signed-skew `v2-skew` PDFs: `+4.0°` CCW rendered at `2776 x 3471` px on odd families `F01, F03, F05, F07`; `-3.0°` CW rendered at `2720 x 3432` px vs. stored `2720 x 3431` XObject on even families `F02, F04, F06, F08`). Holding `crop_mode=False` in both arms prevents stacking `E1` and `E2`.
- **Controlled variables & remaining confounders:**
  - *Controlled:* Model/code pin, `crop_mode=False`, identical pre-gate `pypdfium2==5.15.2` (`scale=300.0/72.0`) RGB page buffer $I_{\text{in}}$, prompts, token budgets, postprocessor, and scorer.
  - *Confounds to log:* Expanded white canvas after rotation changes input pixel dimensions before `1024x1024` letterbox resize (and would alter tile counts if `crop_mode=True` were used—log pixel dims and GPU memory explicitly); `pypdfium2` resamples `v2-skew` pages relative to raw stored XObjects prior to $I_{\text{in}}$ in both arms; vertical rules or sparse checklists (`F03`) could perturb projection variance. Freeze exact tie/rounding code on `dev` (`F01, F02, F04, F07`) before touching `eval_holdout`.
- **Predicted effect (unmeasured hypothesis):** Improved field/table-cell exact match on rotated rasters (`v2-skew`), exact `0`-byte diff and `0` regressions on unrotated rasters (`v1-raster300`), modest CPU overhead.
- **Metrics, explicit denominators, and rejection criterion:**
  - *Primary quality metric:* Equal-weight family mean `exact_matched_fields / total_expected_fields` (and separately `exact_matched_table_cells / total_expected_table_cells`) across the `4` held-out skewed fixtures (`F03, F05, F06, F08` `v2-skew`).
  - *Invariance & cost metrics:* `untriggered_clean_pages / total_clean_v1_pages` (`12` pages across `8` `v1-raster300` docs), clean-control paired delta, post-freeze signed-CCW estimation error $e_{\text{est}} = |\hat{\theta} - \theta_{\text{true}}|$ and post-gate analytic residual $|\theta_{\text{res}}| = |\theta_{\text{true}} + \phi_{\text{applied}}|$, and `median_doc_latency_treatment / median_doc_latency_baseline`.
  - *Rejection criterion:* **Reject `E2` for promotion** if **any** occurs: (1) **any** false trigger or non-identical input bytes on clean unrotated `v1-raster300` pages (`untriggered_clean_pages < 12`), or any field/cell regression on clean controls; (2) equal-weight mean exact-field gain on held-out skewed fixtures `{F03, F05, F06, F08}` is **`< +5.0` percentage points**; (3) any new monetary-total, identifier, table-cell, missing-row, cross-page-link, page-order, truncation, or OOM error occurs; or (4) median end-to-end latency ratio exceeds **`1.10x`**.
- **Smallest execution & promotion cost:** `16` raster PDFs (`8` `v1-raster300` + `8` `v2-skew`, `24` pages total), paired arms with 3 warm repeats after freezing estimator code on `dev`. Low promotion cost (bounded CPU pre-stage with byte-identical no-op fast path; real scanner benefit still requires later real scan fixtures).

### Rank 3 — `E3`: Two-Stage Conservative Zero-Image-Abstaining PDF Text-Layer Routing vs. Unconditional VLM OCR

- **Proposed single pipeline treatment (two-stage gated):**
  - **Strict Abstaining Gate (all pages $1..P$ must pass every check, else the entire document abstains to unchanged qualified VLM OCR):**
