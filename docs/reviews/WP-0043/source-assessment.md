# What can the five archived transitions identify?

The document, its five field predictions and two independent sets of CPU witnesses have different observation boundaries. The stock entry `infer(return_dict=True)` exposes the prepared prompt, ordered IDs, text, counts and finish reason. The historical Q0 wrapper returns text and count and separately recorded inner observables. Neither return exposes a losing raw logit, stream, expert choice or storage alias. The population here is one three-page synthetic F07.warm1 document. There is no estimate of accuracy change, typical storage throughput or timing benefit.

## Two clocks and two page counters

Let P=827 be prompt tokens and x[g] the zero-based returned non-EOS token. Stock scores at input position t=P+g to select x[g+1]. For g=618..622 the native input history H=x[0:g+1] has length n=619..623. The immutable archivals give 6, 1449, 16, 1328 and 128822. UTF-8 bytes 1823..1837 enclose the Unit Price including tags. The equal six-byte value at 1880..1885 belongs to Net Line. At the last field exit the model has yet to consume x[623]. The distinct terminal step consumes x[2557] at 3384 and breaks on predicted EOS before append. The final cache length 3385, 2558 returned IDs, 7617 decoded bytes and three page markers at 0,1145,1896 are recorded. A prefix through the price cannot establish the later stop.

For order 35 the native repetition guard enumerates i=max(0,n−1024)..n−35 inclusive and checks H[i:i+34] against H[n−34:n]. The potential forbidden IDs are H[i+34] of matches. Over the five histories the total tested starts is 585+586+587+588+589=2935 and the maximal shorter prior matches are 2,0,0,1,2. The pinned decoder passes only `gen` here. All five repetition masks are the identity. Three page markers in the prompt supply the expected count; one marker in each generated prefix supplies the current count. The page guard, below its 20000 cap, forbids exactly EOS=1. The support size 129279 is a conditional reconstruction, not a measurement of any score word. Distinct raw score vectors may yield exactly the same emissions, whole public suffix and stop.

The decoder initializes `guard_st={'marker_cum':0,'scanned':0,'page_len':0}` and loops from empty generated history. For the true prefix [PAGE,10,11,12] its state in the order (scanned, marker_cum, page_len) is (4,1,3). At the next call with 13 appended it is (5,1,4). With e=2,c=4 the forced token is PAGE. Resetting the cursor yields (5,2,4) and EOS because the second counting of the old PAGE reaches e. This fault first changes B1's saved cursor, then changes C2. A plain repeated invocation at the same length with an intact cursor does not double-count. The reset state lies outside the stock trajectory with canonical initialization. This witness refutes that particular restoration, while the companion's factorization criterion on reachable states still holds. `cache._uocr_pg` has separate members bmin,bmax,pp,mcum. It initializes from prompt IDs and increments on the pending input at *model entry*, before layer 11. Capturing its mcum cannot provide the page guard's saved cursor.

## The value test and the ancestry test

An actual native call on the CPU guards where H=[PAGE]+p+[7]+p and p=100..133 returns the same tensor object for both guards. Raw, post-repeat and post-page argmax are 7,1,8 for raw values 9,8,4 at 7,1,8. If the forced PAGE was already banned, stock copies that minus-infinity entry before the blanket fill, restores it and returns an all-minus-infinity tensor. That argmax returns integer zero, outside the empty support. Empty support is a measured invalidity.

In CPython 3.12.10 the pinned generator's native bytecode stores logits at offsets 1172,1236,1280 after the head and the two guards. The first instructions *after* those stores are 1174,1238,1282. D follows the pending-position store at 1852. A pre-instruction callback sees the old binding on the store itself. Source line labels, a compiled replica, or a matching digest do not prove the loaded receiver, live frame, observed tensor or successful device copy. Byte-identical C0/C1 on this field admit both a true and a post-repeat placement. The analogue can exercise active subtraction, and phase/unique event/ordering witnesses can distinguish swapped or duplicate copies. Only the stock process supplies the live invocation ancestry.

For a write at absolute token j, the dense logical offset is 4j+lane. With compact physical slot s it is 4s+lane, even if s differs from j. At j=7, 9.0 (00 00 10 41) to minus infinity (00 00 80 ff) first differs at 30 in dense order. At j=1, 8.0 first differs at 6. For unspecified finite raw v, its exponent cannot be all ones. At least one exponent-containing lane 2 or 3 differs from minus infinity. Its *first* differing lane can still be any of 0..3, witnessed by finite words ff000001, ff000100, ff000000 and 00800000 respectively. There are no archived native raw words that could select one lane for F07.

## Ownership, ordering and numerical budgets

For every copied byte j at cut q, a sufficient order is producer(q,j) before device read(q,j), before copy completion, before every following conflicting write/free and before host inspection or reuse of the destination. A serial callback order supplies only CPU ordering. A side-stream copy that waits on the producer, but whose source is overwritten on the compute stream before the copy reads EOS, records minus infinity in C0 or C1 while stock returns the correct token. A same-stream D2H copy is sufficient when all conflicting writes and frees are ordered on that stream or explicitly joined. The native source path and allocator lifetimes must justify that premise. Selective event synchronization avoids a global synchronize but still waits for real completion. Timing and VRAM remain unobserved. Code annotations or host-assigned copy numbers alone do not establish these edges.

Under the proposed shapes, K,V use 2×10×128×2 bytes per position/layer and DASH keys add 128×4, giving c=5632. At B the volume b(t)=c(12t+11); at D it is d(t)=12c(t+1). For t=1445..1449 the ten cuts total 978588160 bytes and the fifteen 129280-element FP32 vectors total 7756800. Their sum is **986344960 bytes = 940.652 MiB**. This corrects the challenger's binary-unit label. Conditional append-only value representation costs 97996800 cache bytes, with unchanged old prefix and full graph reconstruction as premises. Neither sum measures peak device, host commitment, pinned memory, file count, disk overhead or required transfer speed. With duration T seconds available, even a single complete full serialization requires at least 986344960/T bytes/s across those named payloads, additional work excluded. A numerical reserve must cover the implemented schedule and selected representation.

Block-entry state includes non-tensor slots and write sets. Native `DynamicCache.update` rebinds per-layer K,V; DASH additionally rebinds `_dash_idx_k[layer]`. The page handler mutates `cache._uocr_pg`, rotary uses `_page_rope_state`, and the base attaches one fresh shared `_sparse_block_indices_cache` to every layer at each forward. Each mutable sink and its aliases/destination ranges require coverage, as do layer source-ID and allow bindings, communication and pending writes. Normal terminal cleanup restores stage0, the page-scope flag and the two window fields, turns off DASH inference and ends the streamer. It retains router infer parameters. A snapshot of only lengths or a full match of the five output IDs cannot qualify restorable state.
