The live collector emits successful exit codes for GPU/apps/process/Ollama queries; a complete typed process list including creation timestamps; the actual observer identity recorded from its retained Windows process handle; its exact issued encoded query/hash; and observation timestamps. Evaluation excludes only the matching observer row, verifies the issued query/command, and requires a fresh observation (at most 120 seconds). It rejects missing, malformed, failed, stale or contradictory evidence. The PowerShell query includes GPU process rows so any explicitly accounted nonstandard desktop exception also uses creation/executable identity, never a reused bare PID.

Other PowerShell/Python processes have no blanket exemption. Model processes on the GPU remain forbidden even if Ollama appears otherwise idle. Known desktop/WDDM sharing remains disclosed without a hardware-exclusivity claim. No low-memory inference of ownership is used.
