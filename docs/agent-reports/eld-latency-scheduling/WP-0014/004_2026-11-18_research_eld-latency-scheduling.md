## Output, memory and ordering

Each primary had one rendered 300-DPI page, 279 prompt tokens and 57 output tokens. A and B both matched their full three-sentence expected transcription and reading order in every run. A had five receipts, B two. The cold A raw text starts its block at vertical coordinate **103**. All three A results after W start at **104**. That one digit accounts for the entire raw difference. B’s two raw byte sequences match. Within every job the stored raw bytes, displayed result digest, original PDF and reopened historical revision belonged to the same document and attempt. Each operator saved two diagnostic drafts, reloaded and reopened immutable revision #1, then fetched the linked original. The API retained the diagnostic worker’s separate source digest and the common pinned model, renderer, input raster, manifest, dependency and generation settings. The strict byte-equality criterion across all A executions remains unmet. Warm A render took **0.100–0.118 seconds**, warm B **0.091–0.111**. The accepted queue claims one attempt and the native call decodes one document at a time. No independent-document batch interface or pre-render handoff exists on this accepted supervisor. The evidence supplies no population percentiles.
