[ArchiveProjectionEntities.cs](../../../../src/ELedgerCare.Domain/Archive/ArchiveProjectionEntities.cs), [ExtractionStore.cs](../../../../src/ELedgerCare.Infrastructure/Persistence/ExtractionStore.cs), [ArchiveProjectionInitializer.cs](../../../../src/ELedgerCare.Infrastructure/Persistence/ArchiveProjectionInitializer.cs), and [grant-runtime.sql](../../../../deploy/dev/database/grant-runtime.sql) project `\t`/`\n`-delimited cells/lines with `<caption>`/non-cell/`\0`/unbound-`<PAGE>` fallbacks, publish atomically under attempt fencing, grant `SELECT, INSERT` only to `eledgercare_app`, initialize before Kestrel listens in normal startup (`LocalOcr:Enabled=false`), and fail closed with `503 archive_not_ready` (`Retry-After: 1`) or `503 archive_projection_conflict` while `/api/documents` stays healthy.

   - Visually assessed [after-restart-04-seed-r01-metachar-newer-draft.png](../../../reviews/WP-0010/eld-f4-reviewer/runtime/observations/screenshots/after-restart-04-seed-r01-metachar-newer-draft.png), [before-restart-01-archive-browse-9-seeds.png](../../../reviews/WP-0010/eld-f4-reviewer/runtime/observations/screenshots/before-restart-01-archive-browse-9-seeds.png), [archive-page.ts](../../../../web/src/app/archive/archive-page.ts) (`L179–215`), and [receipt.ts](../../../../web/src/app/intake/receipt.ts) (`L123–130`). Because `5` of `6` labels in `receipt.ts` include the word `extraction` whereas `completed` omits it, side-by-side unlabeled pills require brief inference on first glance (`Completed (unreviewed)` beside `Reviewed (Revision #2)` or `Unreviewed`); optional future UI polish could prefix `Extraction:` / `Work-order review:` without changing F1–F4 contracts.
3. **Two non-blocking technical precision notes ([SOURCE-AND-DESIGN-AUDIT.md](../../../reviews/WP-0010/eld-f4-reviewer/runtime/SOURCE-AND-DESIGN-AUDIT.md) Section 2):**
   - **Small-table `EXPLAIN` plan reporting:** On 7–9 rows (`1` heap page), PostgreSQL's default planner chooses `Seq Scan` + `quicksort` (`cost=1.28`), whereas `SET LOCAL enable_seqscan = off` ([explain-plans.txt](../../../reviews/WP-0010/eld-f4-reviewer/runtime/observations/explain-plans.txt) `L15–26`) proves `Index Only Scan using ix_documents_submitted_at_document_id_desc` (`0` Sort node) is genuinely usable for keyset tuple paging without overstating what the default 7-row plan selected.

Unreachable by human interaction (`~80–250ms`), and once the ~2ms URL update commits while a slow HTTP request (`650ms`) remains in flight, `cancelInFlight()` + `seq !== activeRequestSeq` (`L537`) reliably suppress stale responses.
