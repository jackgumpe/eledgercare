## Decisions and rationale

Search reviewed values directly from the highest explicitly reviewed immutable revision, while machine text uses a deterministic durable projection over saved native output. A newer draft does not erase the prior reviewed revision or become reviewed implicitly. A new reviewed revision replaces old reviewed search values, including unknown removals. Exact revision links preserve history. Original machine text remains separately labelled when a human corrects it.

AND terms may span eligible fields/pages within one document. PostgreSQL literal matching, deterministic keyset ordering and source filters keep the first feature bounded. One coherent database snapshot ties hit selection, latest reviewed values and witnesses. Result publication and projection share the existing transaction; backfill readiness is explicit and restart-resumable. Unknown native structure retains honest raw fallback without inventing page coordinates. Product code remains independent of qualification/research/evaluation.

Three fresh diagnostic families each have clean control, layout-only, vocabulary-only and degraded-control conditions. Existing mappers/scorers remain immutable; staged diagnostic measurements are separate.
