Use existing `printed_text`, `normalized_value` and `expected_absences` definitions; allowed normalization is Unicode NFC, line endings and outer whitespace. Text scoring must define reading-order reference, tokenization/alignment and insertion/deletion/substitution denominators; keep text error rate separate from exact fields/cells. Match fields/tables using frozen labels/structure and deterministic alignment learned from dev only. Missing, unmapped, truncated and failed expected items remain in denominators. Count spurious fields, rows/cells and expected-absence violations, including repeated/duplicated output. Do not hide unrecognized content: retain it and disclose what invention detection can/cannot classify. Report per-document numerators/denominators first, then equal-weight family means; variants and repeats are correlated observations. This milestone passes when the measurement is trustworthy and reproducible, regardless of the model's score. Low quality is a valid baseline. Runtime infrastructure failures are distinguished from observed content errors. No benchmark tuning or model changes are permitted to rescue a score.
