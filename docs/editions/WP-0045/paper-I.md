# Mathematical specification and proofs

## When does one extra evaluation define a different transition?

A stock decoder evaluates its last block once and advances the accepted token state. A same-input duplicate and an output-fed repeat add a second physical evaluation but answer different questions. Can we distinguish them when the predicted text is identical, and can finite observations disprove a faulty state transition? This amendment supplies the transition, guarded readout and acquisition equations used throughout this edition.

Gemini's independent written review of Edition 02 found three counterexamples. The old TOKEN listing always decodes its first branch and its final return commits even on the private reading. The old A2 admissibility bracket admits a NaN subsequently hidden by a guard. The old RECONCILE listing can repeatedly request a deterministic field below threshold, because its feasible set stays fixed after a noisy read. Each example changes a premise in the operational specification.
