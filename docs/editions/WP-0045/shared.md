## A1 / Which state moves with a token?

At target position t, s contains the accepted history and mutable model and guard state. An immutable snapshot xi binds the pre-token prefix, cached keys and values, routing/DASH state, offsets, counters, guard cursors, evidence, weights and execution parameters. The preceding block emits a vector a in R^d; one target-block call B11 returns hidden h in R^d and candidate current-slot contribution u. Dec returns the token ID y and post-guard state g. Only the selected tuple T=(u,y,g), combined with matching native contributions of other layers, can advance s.

> (h_b,u_b) = B11(x_b; fresh_b(xi)).  T_b = (u_b, y_b, g_b).
> x_stock = x_duplicate = a; x_k1 = h_stock; x_k(i+1) = h_ki.
> (y_b,g_b) = Dec(h_b; private_guard_b(xi)) for each required readout b.

Validate mode, K, selector b* and commit flag c before any call. Stock requires K=0 and selects stock. Duplicate requires K=0, computes both stock and duplicate from a, decodes both through A2 and retains both readouts; preregister either. Literal evaluates stock followed by K>=1 output-fed calls and decodes its final kK. Disjoint scratch includes mutable storage reachable via aliases, RNG/guards and external effects. Immutable parameters may be shared. Each replacement slot starts from xi; only h is fed forward. Record branch inputs, outputs, guard/score provenance, selected tuple, all conflicts and missing evidence.

On a duplicate, compare both native readouts, projected updates and post-guards at all predeclared cuts. Remove only the declared branch identifiers in a parity comparison; equal token IDs alone cannot confirm parity. A missing first readout invalidates a supposedly checked second selection. After any exception continue independent diagnostics and report every observed conflict and missing key, with sources and earliest causal cut where ordered.

> D = M if any conflict; else U if any required witness missing; else P.
> s_next = CommitOnce(s,T_b*) iff D=P and c=true; otherwise s_next=s.

CommitOnce publishes the complete selected transition atomically once against the still-current snapshot. A stale snapshot, failed validation, cancellation or publication failure discards all scratch; record what was witnessed, including rollback. A private success returns T_b* and zero commits. An accepted ordinary step makes one transition across history, cache and guard. An EOS decision uses its bound native terminal transition; it never appends a phantom input after termination. If atomic publication/rollback or effects isolation cannot be established, its guarantee is unavailable. A witnessed leaked write is a conflict regardless of final token equality.

Proof. Before publication, all writes target mutually disjoint private slots and no path reaches live s. Induct on the number of evaluations: xi and s stay fixed; the next input follows the equations. Selection indexes one stored tuple, so private/rejected exits are identity. A single successful publication is the only state-changing edge. With B(x)=x+1 and a=11, the duplicate returns 12 twice. Selecting duplicate commits (u:duplicate,12,g:duplicate). Substituting stock's update passes the token comparison yet violates A1. A literal call at K=1 instead produces 13. Duplicate adds a physical call and zero feedback steps.

## A2 / What makes a guarded winner admissible?

Each phase is a native typed score array indexed by token j in V={0,...,v-1}; z0 is the raw head, z1 follows no-repeat, z2 follows page. Bind dtype, byte order, shape, logical strides, offset, vocabulary ordering, native cuts, actual execution order, pre/post guard state and copied phase bytes before in-place mutation. Reject contradictory shapes, representations, NaN and either infinity anywhere in z0, including later banned IDs. Missing evidence has its own unresolved key. A finite challenge uses one aligned word per ID displayed in hexadecimal FP32, independent of host byte order.

> M_D(z)[j] = bits(z[j]) if j belongs to D; else bits(native -infinity).
> bits(z1) = M_N(z0); bits(z2) = M_P(z1); A = N intersect P.
> A nonempty => y = smallest j in A maximizing numeric z2[j].

N and P are independently reconstructed native support sets. In the bound OCR source (WP-0042 scoring and source cuts), N uses the generated-history suffix of 34 IDs: when n>=35, for each matching 34-ID prefix starting at i=max(0,n-1024)..n-35, ban its successor H[i+34] except whitelisted IDs. H excludes prompt IDs. The pinned whitelist is empty. Before each page call, replay newly scanned generated IDs once, update scanned length, marker count m and length l since the last marker. Expected page count e comes from the prompt; cap c is in tokens. When e<=0, permit all and leave state unchanged. Otherwise apply the following in order: m>e permits only EOS; 0<c<=l forces PAGE if m<e and EOS otherwise; m<e bans EOS; otherwise permit all. Witness the actual native branches/state and forced-slot restore from the immediate predecessor. A mask inferred from the final score vector cannot supply these witnesses.

Proof. On each surviving ID both masks preserve identical bits; a blocked ID becomes exact negative infinity and a later permit preserves that word. Raw finiteness and nonempty intersection imply a finite maximum. Ascending ID breaks numerical ties including +0/-0; byte comparison distinguishes their encodings at each cut. Diagnose each phase relative to its own observed predecessor and native mask, retaining simultaneous faults, missing obligations, earliest witnessed location and support failure. A failed row has no winner. For [5,NaN,2] with ID 1 page-banned, final [5,-inf,2] would choose ID 0 under a final-only check; at raw ID 1 the amended rule records M. If repetition bans the ID the page guard forces, A is empty, even when an implementation returns a numeric argmax.

## C1 / Which observation can change a decision?

Exact mode starts with finite set F of feasible printed tables y=(y_0,...,y_(m-1)) satisfying trusted constraints. Given truth in F, uniform prior, noiseless answer and equal query costs, partition F by field i. If bucket v has n_v members, its probability is n_v/|F|; its expected contribution to remaining size is n_v^2/|F|. Minimize sum_v n_v^2 among varying fields, choosing lowest index on ties. Empty F gives CONFLICT, singleton gives IDENTIFIED. Exact filtering retains the truth, removes at least one element and fixes the field. At most min(m,|F_initial|-1) queries suffice. In the five-table example 000,001,010,110,210, the three field costs are 11,13,17. Greedy field 0 can take three reads; field 1 first needs at most two. The objective proves a one-step expectation only.

For noisy mode, p_y is the current normalized posterior on candidate y, H is all retained history, b is the remaining integer acquisition budget and U the set of used primitive evidence sources. Action i names a source s_i and a row-stochastic conditional law L_i(o|y,H) over finite outcomes o. Use conditional laws valid at the decision being scored. After an observation, other laws must apply to that updated history, e.g. through explicitly justified conditional independence. The finite wire supplies these laws as assumptions; interdependent channels in general require a joint/sequential law. Distinct names alone establish no independence.

> m_o = sum_y p_y L_i(o|y,H); p^o_y = p_y L_i(o|y,H) / m_o for m_o>0.
> G_i = sum_(o:m_o>0) m_o ||p^o||^2 - ||p||^2.

A new admissible observation with b>0 consumes one acquisition and records its primitive source. Zero marginal on an observed outcome gives MODEL_CONFLICT with no posterior. A repeat from a recorded deterministic source changes neither odds nor budget; unobserved data supply no likelihood update. If max_y p_y >= tau, return ACCEPT at the calibrated threshold tau. Otherwise return UNRESOLVED when b=0 or no unused source has positive gain. Else query the smallest ID attaining maximal positive gain. A proposed query is not evidence. Log acquisition failure/unavailability and retire that attempt or exit unresolved; never spin waiting for unavailable evidence. A future noisy action may revisit a field through a genuinely new measurement with justified history-conditioned law.

Proof. For each y, sum_o m_o p^o_y = p_y. Expand squares to obtain G_i = sum_o m_o ||p^o-p||^2 >= 0; gain vanishes exactly when each positive-probability outcome leaves the posterior fixed. With no further acquisitions after exhausted budget or eligible sources, successful acquisitions are bounded by min(initial budget, number of fresh sources). This bound assumes a terminal response to missing evidence. Simultaneous equal action costs justify comparing gains directly. Acceptance depends on model calibration and truth coverage; an incorrect 0.99 posterior is possible. No likelihood calibration or OCR benefit has been measured here.

For two equiprobable tables (20,38),(28,30), a binary symmetric 9:1 signal has posteriors (0.9,0.1) and (0.1,0.9). Gain is 0.82-0.5=0.32. After one positive read, a deterministic reread conditions on history and has gain zero; with tau=0.95 and no fresh source the answer is UNRESOLVED. A second conditionally independent 9:1 positive with another source yields (81/82,1/82) and passes tau. An action with identical output law for both tables has zero gain even if both crisp field buckets are singletons.
