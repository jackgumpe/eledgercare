# WP-0017 pre-output design

## Interventions and estimands

The experimental unit for A1 is one fixed three-page RGB window. Use the BF16 checkpoint at `0480966938291445591f69f08a13b041c073a96a`, WP-0015 engine `61bec47689dcdf272a525185013f2dce6335fa24` and WP-0016 wrapper `c7b2ee3663317e42a0e9bdd7ff9e17f16747d2cf`. Hold prompt, visual preprocessor, 300-DPI PDFium raster hashes, page order, tokenizer, generation arguments, FP32 decision arithmetic, page/ngram guards' semantics, maximum length, and stop convention fixed. Record implementation counters per window and deltas of cumulative counters. A requested kernel that falls back is an implementation-path treatment and cannot establish that the unavailable kernel caused a change.

| Switch, bit order | Off | On | Scope that must be isolated |
| --- | --- | --- | --- |
| S0 no_text_streamer | Native TextStreamer.put for every returned non-EOS token and end | Suppress text callback | Preserve original token history, UTF-8 stdout and page projection. With S3 on, stream accepted non-EOS tokens in order at burst return, suppress post-EOS tokens. Report cadence difference. |
| S1a packed_moe_prefill | Reference per-expert dispatch for many-token prefill | Carbon sorted packed grouped-MM dispatch, reference packed fallback when unsupported | BF16 routed gate/up and down operations for prefill only. Preserve S1c setting in both backends. Count grouped success and fallback by layer. |
| S1b packed_moe_decode_bmm | Native per-expert single-token dispatch | Carbon selected-weight batched multiplies and native Carbon accumulation order | Single-token decode only. Packing/storage must not silently switch prefill or fusion. |
| S1c fused_gate_up_proj | Separate gate and up GEMMs | Concatenate gate then up, GEMM and split before activation | Apply to routed, shared and layer-zero dense weights in BOTH phases. Exercise with S1a/S1b both off and separately enabled. |

Carbon allocates max(4096, prompt+2048) before max-cap clamp/block rounding. Report effective capacity, layer/step coverage and growth. |
| S3 gpu_burst_stride_8 | Host guarded greedy, immediate EOS stop | Device no-repeat/page guards, accepted prefix from stride-eight burst | Device guard equivalence, EOS truncation and speculative post-EOS forward count are part of this switch. Keep S0 choice independent. |

`rules.py:matrix` specifies fourteen bit vectors. Native 000000 and Carbon 111111, six additions 100000, 010000, 001000, 000100, 000010, 000001, and six removals 011111, 101111, 110111, 111011, 111101, 111110 in switch order. Run ordinary free generation for each vector and both windows. Bind genuine native and Carbon control paths and evidence showing new endpoint implementations reproduce their complete frozen WP-0016 window token-ID arrays under identical raster, prompt and generation inputs, EOS/stop, complete page sequence and per-page boundaries. If the matrix aliases a real endpoint, record that fact and compare its measured emission to the frozen array. If it uses a new implementation, compare its own fresh output as well. Matching text, argmax of a forced run, or matching only the two IDs is insufficient. A mismatch blocks attribution until any harness fix has a new source binding.

## Anchors, natural history and counterfactual branches

Before opening new outputs, the reviewer pins byte hashes and emitted integer histories of both original orders for native/full Carbon at 019 and 037, their PDF, the six ordered RGB hashes, prompt/tokenizer/model and frozen generation parameters. Ordinals below are zero-based emitted-token offsets, excluding prompt and EOS. Independently audit the reported 417-token common prefix at 019 and the first differing token at 037 index 7 (17979 '291' versus 16234 '290'). Record actual lengths and next IDs, and whether repeats match. Resolve inconsistencies against immutable artifacts before running the sweep.

On 019 bind the third page, page 21, line 2, and alternatives `I08O1-388` and `108O1-388`. On 037 bind the first page, page 37, line 2, and alternatives `8OI10-774` and `80I10-774`. For each field freeze a UNIQUE structural locator from the original native raw history before output (physical page, field's fixed label/text immediately preceding the ID in the prose block, string/byte offset and raw block ordinal). The ordinary free ID is the complete field value at that same unique site, bounded by the field delimiter or end of block. Never search for either competing value to locate a site in a new output. Missing/ambiguous field, moved/malformed structure preventing matching, different value or abstention fails restoration, with an explicit reason. Output length and box-number drift can change the free prefix length. Match a field by its frozen label and page/structure, never use global index 417/41 as its free locator.

Use frozen TOKEN IDs as the prefix. Tokenize each full alternative in its actual left context with pinned tokenizer, special-token insertion off and no whitespace cleanup. Find the latest common token boundary that (1) precedes or equals the byte start of the field, (2) permits **both** continuations to the final ID byte, and (3) retains an exact prefix of the frozen/emitted token IDs. E.g. include the leading space on page 21 if fused into ' I'. Verify decode(prefix+span) equals decode(prefix)+the exact intervening bytes and identifier for each path. Check complete native and Carbon branch token sequences against historic emitted spans on their respective histories. For noncanonical generated token histories preserve the existing prefix IDs and use an explicit compatible suffix with exact byte-level roundtrip or mark unalignable. Never silently re-encode the whole prefix, truncate at the differing glyph, include an extra following delimiter, or compare means per token. Retain resulting prefix IDs/hash/length, full continuation IDs and decoded bytes, byte offsets, and first divergence index within each branch. The common token prefix shared *within* the two span branches must condition top-five capture at their first unequal token, even if it lies inside the field.

For every configuration probe 019 on the frozen native prefix and 037 on **both** its frozen native prefix and its own free-running prefix up to the anchored field. Compare 019 free and native prefix hashes too. Report an upstream history change separately if they differ. Force one token at a time through the same prefill, KV, page-RoPE, attention, routed expert and guard arithmetic as that configuration during normal decode. Replay all prefix tokens, including the coordinate on 037 and the entirety of any later pre-ID differences. Reinitialize or exactly fork every mutable cache, guard, current logits and logical position for each branch. Passing the historical transcript as one prefill string changes the operator and invalidates the probe.

For input pixels x, run config c, prefix p and complete suffix y, record

`ell_c(y|x,p) = sum_k log_softmax(float32(z_c(x,p,y[:k])), dim=vocab)[y[k]]`,

using effective PRE-argmax logits after the ordinary page/ngram guards. Save pre-guard raw and post-guard statistics separately if they differ. FP32 log-softmax must cover the complete vocabulary, even when the chosen token is outside top five. Log every target's ID, conditional log probability, sum in nats (no length normalization), sign and full-span odds contrast `D_c = ell_c(native ID) - ell_c(Carbon ID)`. A masked/nonfinite target gets explicit guard/coverage status; do not use it as a finite selection statistic. Keep top five IDs, decoded pieces and FP32 logits at first branch divergence, including both competing IDs/logits even below rank 5, and top-1 minus top-2 effective logit margin. Document ties and actual greedy tie-break. Save first structural divergence and its top five for the early coordinate when applicable. A full-span sign need not agree with greedy branch choice.

With pN the full frozen native prefix, change from D_native(pN) to D_c(pN) reports a path effect at identical history. D_c(p_free)-D_c(pN) reports the effect of the entire observed history shift within c, provided both fields align. At 037, this difference alone cannot attribute the cascade exclusively to the early coordinate if more preceding tokens changed. Retain the first difference and total changed token/prefix alignment. These are two conditional traces, without population-level or kernel-level generalization.

## Ordinary latency and the A1 decision

Measure uninstrumented, single-arm, pre-warmed ordinary free-window elapsed time using identical engine.read boundaries (or one coordinator-pinned common ordinary boundary for all rows). Preserve 019 and 037 separately in seconds, summed two-window seconds, window output-token counts and executed forwards. Report `T_native-T_add_i` and `T_remove_i-T_full` per window and in sum. These are local marginal savings conditional on the other five settings, and cannot be added up into a 60-page forecast. Record process cold start, initialization and exclusion. Record actual device-synchronized probe prefill milliseconds and decode milliseconds per measured forwarded token with explicit interval and denominator (forced history, branch continuations, excluded setup and speculative/unused forwards). Instrumented probe milliseconds, startup, and A2/A3 accept-to-durable-commit seconds are distinct. Bind time from measured baseline windows plus startup/probe multiplicity and overhead with margin and hard maximum; do not use a four-minute speculative sweep deadline. Missing budgets can stop with a documented partial result.

After endpoint parity, compare all 14 configurations on both free fields, full conditional score table and ordinary timing. Single additions test sufficiency on native, removals test necessity on full. An effect present in just one background is background-dependent. For each restored ID report its single-add and single-remove causal contrast and direction on the common history. Do not call a unique causal kernel if multiple treatments fit, the observed effect is confined to a cascade, or unresolved numerical/backend coupling remains.

If no single removal restores both free IDs, use `rules.py:qualifying_pairs`. A switch is eligible when its addition changes an ordinary uniquely anchored native ID to a different complete identifier. A missing, ambiguous, or malformed field is counted separately. A valid greedy flip qualifies even for an arbitrarily small conditional score change. Otherwise use only the same two frozen-native histories. For each window w independently repeat the native and full endpoint probes with new prefill/cache state and original inputs. Define its noise floor E_w = max(0.00001 nats, abs(D_native1−D_native2), abs(D_full1−D_full2)). For each addition, if its first paired displacement d1 = D_add1−D_native1 exceeds E_w in absolute value on either window, replay the addition's forced-native probe on both windows. Require some one window with sign(d1) = sign(d2), d2 = D_add2−D_native2, and min(abs(d1),abs(d2)) > E_w. Record all inputs, floors, exact comparisons, missing evidence and the reason for admission. Replaying at most six additions and the two endpoint probes accounts for actual uncertainty. Enumerate unordered pairs of admitted switches only, once, in switch order. Maximum 15, zero if fewer than two switches qualify. A coordinator may release fewer because of a hard budget, but an incomplete predeclared comparison ends unresolved without surgical selection. If a single removal restores both fields, omit interaction runs. A pair restore alone supports interaction-compatible recovery. A unique pairwise causal mechanism would require additional evidence.

From the evaluated removals that restore BOTH ordinary free IDs with complete bound ordinary timing and forced-span evidence, choose minimum number removed, then smallest sum of ordinary 019/037 seconds, then lexicographic switch order. No requirement that individual greedy recovery reverse a full-span sign. Missing/incomplete A1 evidence, endpoint failure, no eligible restoration or a hard cap yields no frozen surgical arm. Freeze at most one candidate with bit vector, engine SHA, scorer/title/pins, and all decision inputs before any A2 model output. No tuning on dev or A3.

## Development and qualification

Generate a new 18-page raster-only service packet in a private new namespace from one fresh 256-bit seed. Retain seed in scoring custody. Six three-page windows have one page per font family. Rotate fonts through page positions. Every page has one critical prose header ID and two critical table IDs. All 54 are unique. Balance I/1/L and O/0 within font and placement; vary order and numeric suffix. Windows/office font bytes are pinned. Generate independent source from random values and layout primitives. Render from PDF bytes using the same PDFium/300-DPI RGB rule as inference. Inventory PDF, pixels and custody key separately. Inference receives source PDF and ordered raster hashes only. Public family name is `id_ablation`. Developer generators, key, secret seed and truth-bearing test outputs stay out of inference release inputs. The independent reviewer may use custodian-approved commitment equality checks to verify zero held-out duplication without design authors opening any escrow packet.

A2 has six fresh single-arm processes in order **native, full, surgical** (AB) then **surgical, full, native** (BA). Use identical excluded warm-up requests across arms and both orders and record those exclusions. One complete 18-page document per arm/order, six scored three-page windows each, **36 scored windows** total. Time source acceptance through durable prediction publication under WP-0015 document boundaries. Blind-hash all predictions/raw/timing before separate-process unchanged scorer and title sensitivity. Matched native→surgical paths use the WP-0016 definition: trial incorrect/unflagged and baseline correct or flagged. Report changed persistent errors separately; a repair elsewhere cannot cancel a new miss. Require complete, uniquely linked page/path pairs and original flags in each view/order to validate the comparison. For each order o set full saving F_o=T_native,o−T_full,o and surgical saving S_o=T_native,o−T_surgical,o. Require F_o>0, S_o≥0.60 F_o for BOTH orders and min_o(S_o)>max(|T_native,AB−T_native,BA|,|T_surgical,AB−T_surgical,BA|). Report full arm spread separately. New unflagged count must be zero in all four native-vs-surgical views/orders. Strict spread comparison rejects ties. If A2 is incomplete, fails or gives a nonpositive full saving, stop before A3.

A3 reuses the WP-0016 structure for H (4 pages) and A (60): native→surgical then surgical→native in isolated processes, three excluded one-page warm windows per arm, six excluded per order, 22 scored windows per arm (2 H + 20 A), 44 per order. Audit stop/EOS, expected pages, hashes, complete sequence and source links before releasing scoring keys. On EACH H/A × frozen/title × AB/BA require complete matched pages/paths, zero new wrong-source links, delta CER ≤ +0.01, delta cell accuracy ≥ −0.02 where applicable, zero newly unflagged critical errors, and true emitted flags unchanged. Require peak board VRAM ≤10,000 MiB with observed coordinator sampling (report cadence/limitations), and zero static cache growth when used (show positive coverage; explicitly report dynamic-only if S2 disabled). On A require positive native-to-surgical saving in both orders and min saving strictly larger than native and surgical repeat spreads. Stage failure retains ordinary native as reference. Separate the experimenters from independent operator, scorer, and acceptance authority.

Report signed net critical recovery (repairs minus regressions and abstentions), per-path CC/CW/WC/WW, malformed headers and pages affected. For Windows on A report signed net repairs relative to its separate prediction and per incremental second, using 15.6546455 s as its document baseline. Keep undefined denominator explicit. Offline margin flags may use fixed predeclared strict top-two gap <0.125 logits at field tokens (minimum effective margin per aligned emitted ID); show evaluable/correct/incorrect, true/false alarms, missed errors, abstentions, number of evaluable fields/all critical fields, and absent/malformed/uninstrumented spans. With A1-only probes use only aligned positions actually measured and label that partial coverage. Do not transfer a margin from a forced counterfactual branch to a free-emitted field or charge instrumented time to the gate. Leave original flagged=false behavior intact.

B remains sealed. This design neither estimates training effects nor admits grammar, CUDA graph batching or Linux trials.
