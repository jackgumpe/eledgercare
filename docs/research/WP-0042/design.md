# Can a private call to block 11 reproduce the stock price decision?

The native reader emitted **$28.50** from page 1, table 2, row 2 (header included), column 5 of F07.warm1. Would a separate call with the same hidden vector and history emit the same five IDs, leave the same state, and let the original document finish? A wrong answer would make any later change to this block hard to interpret. A correct answer on this field establishes fidelity on one already-correct synthetic example. The archive supplies zero complete block-entry snapshots across the five decisions. The six constructed CPU examples test ways a proposed experiment could give a misleading answer.

## What evidence makes a captured state sufficient?

Gemini A1 expanded Draft 2's state record to cover the partially advanced model, page and routing metadata and guards. Edition 3 gives a more precise criterion. For the reachable full states θ under a fixed configuration, let σ(θ) be the recorded fields and Y(θ) the complete declared outputs and logical post-state. A function f exists with Y=f∘σ exactly if {Y(θ) | σ(θ)=c} is a singleton for each attained record c. Necessity follows by evaluating f(c). For sufficiency choose any representative for c. The singleton condition makes that choice immaterial. The result proves existence on the specified reachable domain. A restore implementation must separately demonstrate that it constructs a state in the same class.

At entry the first eleven layers have appended x[g], and layer 11 still holds t earlier positions. Thus the conditional K/V length vector is (t+1 repeated 11 times, t). Layer 0 already advanced _seen_tokens to t+1. At k=0, require eleven 1446s, one 1445 and 1446 seen tokens. The same split is expected in the active DASH key lengths. A post-block append makes all lengths t+1 without changing _seen_tokens. Model-level page candidacy has already consumed x[g]. Feeding it the same token twice can corrupt subsequent page state even when an individual price token leaves its marker count unchanged. Inspect the length and binding of each layer separately.

For the order-35 no-repeat guard, take 34 distinct IDs p, and put either p,1328,p or p,6,p in the visible generated history. The first history bans 1328 and the second bans 6. Neither an isolated price nor its four-piece repetition suffices to make a 35-gram. A binary toy state with a true guard bit and a counter completely determined by t gives a different boundary case. Dropping the counter preserves sufficiency there, dropping the guard bit need not. The toy witness uses a 128-token window. The three-page F07 run uses 1024. The construction demonstrates guard semantics without proving reachability at a particular native hidden vector. Test the claimed complete record by using only it for each independent restore and comparing both transition and continuation against stock. Any different observed result refutes sufficiency of that implementation and execution contract jointly.

## What does a faithful private copy do?

Gemini A2 identified shared K/V, DASH, globals and guard state as possible sources of mutation. Its proposed deep clone of named objects does not specify what the active call reads and writes. Give each logical byte reference an identity a=(device, live allocation generation, byte offset). For private branch i, the map φᵢ must preserve alias equivalence in both directions for every referenced observable byte. With Wᵢ its possible writes, Rᵢ its possible reads, and P the protected original, require Wᵢ∩P=∅ and Wᵢ∩(Rⱼ∪Wⱼ)=∅ for i≠j. Include object slots (object identity, attribute/key/index) and aliased objects in the same condition. Frozen read-only weights may be shared under a documented no-write proof. Rebinding an aliased dictionary key can corrupt the original while every old tensor byte remains intact.

Build a typed object graph before replay. Canonical logical names identify model, generator, private runner, caches, per-layer module attributes and stack-local continuation values. Map each underlying storage once with size, live lifetime, device, element type/width and addressed interval union. Rebuild views with the original shape, stride and element storage offset, including non-contiguous and overlapping views. For byte-width e, offset o in elements and index vector j, the byte address is e(o+Σᵢ jᵢsᵢ) plus the byte lane; sᵢ are strides. Allocate disjoint private storage for all potentially mutable ranges, preserve exact alignment/layout constraints required by the operator, and validate the inverse alias relation as well as byte values. Identity/version checks at a single address cannot distinguish recycled allocations. Keep references live through the last completion event. Reject unsupported tensor subclasses, external writable handles, non-addressable/overlapping storage of unresolved extent or non-reconstructible layout. Never serialize unrelated allocation slack. If an active read can access bytes outside the proven initialized union, withhold restore.

Recreate mutable lists, dicts, tuples' reference edges, shared subobjects and typed scalar fields from a memo table. Preserve key iteration order where source can observe it, missing versus None, and the raw identity relationship between multiple roots. Compare **within** a run by live allocation and object identity; compare **across** independent allocations by stable logical paths and alias classes, including creation, replacement and retirement of bindings. Bind the full generator frame by an explicit continuation record and program counter, not by attempting to pickle a suspended Python stack. A branch runner needs its own module attributes, global bindings, tokenizer/streamer state as applicable, and redirected private output. An isolated process loaded serially can supply an independent namespace; restoring the native graph is still required. An in-process implementation needs a proven private namespace and module graph for all affected functions, with no transient writes into the paused source. Copying _INFER without changing both module roots that refer to it leaves one path aimed at stock. An unidentified writer ends admission.

For each stream producing an observed value, record a producer event before the observer read, wait on that event in the capture stream, copy to independently owned storage, and record a completion event. Make every stream which might mutate, recycle or release the source wait for copy completion. Wait for device-to-host completion before reading, hashing or reusing host buffers. Use an explicit device-wide synchronization at a declared phase boundary when individual dependencies cannot be established. Record observed stream order, event edges, lifetimes and completion receipts; missing ordering evidence is incomplete. A host reference, detach, queued copy alone, or subsequent host synchronization after overwriting r cannot recover its original bits.

Induction over ordered stores proves isolation under those assumptions. Corresponding private reads initially agree. A store updates exactly the corresponding private bytes and their aliases, and disjointness excludes the original and sibling. Apply the same reasoning to bound object slots. In overlapping views u=A[0:3], v=A[1:4] of [10,20,30,40], writing u[1]=99 yields (v[0],source[1])=(99,20). Split aliases yield (20,20); borrowing source yields (99,99). At t=1445, illustrative head-0 BF16 row offsets are 369920 in contiguous [B,H,S,D] and 3699200 in [B,S,H,D] at H=10,D=128. A contiguous FP32 index row at width 128 would be 739840. In this source a fresh cat result can change the **binding** with the old allocation entirely intact. A differing first byte can occur after the nominal row start. Treat these as diagnostic alternatives.

## Can a caller commit once and preserve the handoff?

Gemini A3 added two probes to resolve local and handoff faults. Let Bₖ be the pre-layer-11 cut, Dₖ the post-decision cut after guards, selected ID, single non-EOS append and calculation of the next position. Include the immediate block exit as a separately observed intermediate. Tₖ maps Bₖ to Dₖ, and Hₖ maps Dₖ through consumption of the selected ID, model-level handling and layers 0–10 to Bₖ₊₁. The source cut table binds each of these to an instruction boundary. For k=4 stop the private trajectory at D₄ with the pending input equal to the closing delimiter and next position 1450. The original owns the document after this cut.

Use five independent anchored starts each for P1 and the two calls of P2. Then start linked J1 and J2 independently from B₀. J1 steps only from its own state. At each J2 step fork **its own current Bₖ** twice, take two equal-input calls, retain both records, select a's entire post-state as the single successor and discard b. Pass the chosen private ID to its own next model entry. Never substitute archived future IDs, native future hidden vectors, or later snapshots for these handoffs. Do not reuse results between anchored and linked trials. Audit instance ancestry, object disjointness and per-layer append/guard counts. This schedules 15 anchored plus 15 linked final-block calls on the five-price-decision path. Four between-decision lower-layer handoffs per linked trajectory are additional. The fifth D records its exit. A divergence is observed at its first conflicting cut. Stop an incompatible trajectory and retain every later scheduled item as missing; equality on the surviving prefix cannot qualify the field.

If equivalent entries have equivalent T outputs and full post-states, and equivalent post-states have equivalent H outputs, induction through the four bridges establishes parity for all five outputs and the field exit. Starting with c=30, T(c)=c+1 and H(c)=c, a bridge-only error gives correct first post 31 then next entry 32 instead of 31. A local extra increment first gives post 32. With a compensating bridge subtraction the next entry returns to 31 despite the incorrect post. Dual cuts locate the first **observed interval**, subject to complete projections, deterministic operation and faithful observations. They do not isolate one code instruction. Boundary example for single commit: at prior length 31, a and b append index 31 in block 0 independently and each ends at (length,counter)=(32,31). Reusing a for b adds index 32 in block 1. Trimming length to 32 leaves the wrong counter 32 and block record. All five F07 positions have floor(t/32)=45. This field cannot demonstrate native rollover.

## How can scoring detect in-place masking and missing data?

Gemini A4's pre-mutation requirement applies at the custom generator, before the no-repeat guard. Its separate validity premise is essential. Two raw vectors (4,3) and (4,2) can both become (4,−∞). No function on their common image can recover both losing values. Capture owned, ordered raw and after-each-guard vectors. Reconstruct allowed IDs independently as specified in [the scorer contract](scoring.md). A finite set of rows can have matching invalid fields; identical NaN payloads fail hidden/raw validity. A permitted positive zero versus negative zero passes finiteness but fails exact byte equality. A correct ID can coexist with a lost route or altered cache. Compare full objects and report the first distinguishing coordinate.

Gemini A5 replaced an ambiguous binary product with ordered outcomes M (observed mismatch or invalidity), U (unmeasured), P (pass), with M<U<P. Expand the frozen obligations in the scorer contract before any runs. Each comparison of populated fields contributes a distinct atom. The field verdict is the minimum of all atoms. If one atom is M it is the minimum, else if one is U no conjunction of the remaining passes completes the evidence, else every atom is P. Keep all missing, invalid and conflicting fields even when M wins. Example: matching anchor P2a with no P2b makes U; a known differing raw byte in P1 plus that missing P2b makes M with the P2b obligation still open. Source protection and actual terminal continuation are mandatory atoms. All five reference snapshots are absent, so **the native qualification today is U**.

## What this field could decide

For the observer hypothesis the unit is one complete stock document. Require full equality of every exposed, deterministic output on the untouched and observed run, plus terminal validation, with one scheduled pair. One differing ID, prompt or byte falsifies public fidelity on this document. Failure to finish leaves an incomplete pair unless there is already a witnessed violation. For private parity the unit is one scheduled field with five dependent positions. The decision rule is all obligations P; disclose counts by arm and position plus one field verdict. Any measured mismatch or invalidity rejects this candidate here. Missingness with no conflict withholds judgment. Neither a public match nor a full field pass establishes fidelity on unseen pages, changed warm-up, other hardware or new software.

The complete predecessor argument for other hypotheses is attached as Edition 3 pp. 7–9 (digest and unchanged scope below) and carried in the WP-0041 analysis §§2–4. For a unique finite winner a and rival j on the same allowed set, put m=zₐ¹−zⱼ¹ and δᵢ=zᵢ²−zᵢ¹. Then zₐ²−zⱼ²=m−(δⱼ−δₐ). A 0.40 lead falls to −0.05 if the rival gains 0.30 and the winner loses 0.15. Equality is a tie subject to all rivals and the native tie rule. The RMSNorm derivative and four-way history contrast in Edition 3 assume comparable inputs. A changed full private history despite equal IDs or changing allowed sets breaks a naive attribution to the extra call. No recurrent scores were observed. This handoff proposes no change to that mechanism.

For a future accuracy comparison, Cᵢʳ is exact signed-minor-unit correctness for arm r in eligible independently sampled family i, including wrong, abstaining, failed or missing answers as zero with separate counts. Against matched native L1 (and separately crop), recovery R contributes +1, regression G contributes −1, so Δ=(R−G)/N. R≤G falsifies a positive observed gain for N>0. N=0 here. A resource hypothesis needs matched total times per incoming page including zero-trigger pages. With K triggered cells, overhead a in ms/page and marginal loop and crop costs bᵢ,cᵢ in ms/cell, mean difference is E[a+Σᵢ₌₁ᴷ(bᵢ−cᵢ)] under nonoverlapping accounting. For constant b,c and c>b, strict savings require E[K]>E[a]/(c−b). With a=2,b=3,c=11 a rate of 0.25 cells/page breaks even. A nonnegative measured difference falsifies a speed gain on that workload. The historical K/V+DASH end payload is 228771840 bytes at 3385 positions. Neither allocator peak nor future retention time follows from those bytes. No accuracy, timing or hardware-effect estimate has been made.
