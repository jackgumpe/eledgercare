## Compare live state at the cut, not cached guesses

The record includes all logical K/V and DASH index tensor **values**, metadata and alias graph for twelve layers before and after the step. For expected batch 1, K and V have [1,10,ℓ,128] BF16 and DASH keys [1,ℓ,128] FP32; establish actual dtype/shape/stride and device for every object. Compare garbage-free logical payload, plus exact addressed backing ranges needed to restore overlapping views. Capture native state for both model and generator, which can reference the **same** cache through different paths. In private execution restore these edges to a single private object. Frozen decoder weights and immutable configuration may be addressed by digest; per-layer mutable attributes and globals need value and identity evidence before and after the scope of each private fork.

For example, _uocr_pg is **whole-model** state, _page_rope_state and _dash_idx_k are keyed by layer, _dash_dec_allow is a module attribute populated at model entry, and __globals__['_INFER'] has an OCR-module alias. Preserve every alias of pf_cnt, coordinate tensors, per-layer _sparse_source_input_ids and shared scratch dictionaries. Keep an inventory of initialized diagnostic flags, writable buffers (including nonpersistent rotary buffers), TextStreamer cache/prompt/print state, generator lists, stopping and output sinks, cache list slots and model config fields. Account for time/counter callbacks and environmental state with source justification when excluded from logical numerical comparisons. A branch may publish streaming output only into its isolated sink. Preserve native streamer state on the protected document and verify its decoded output after normal completion. Unknown active membership or mutability is a missing obligation. A reported unsupported path is an observed predicate conflict if it contradicts the admitted path.

For the stock run use historical path constraints expressed as actual predicates, including no ring, DynamicCache and DASH+FP32 decode. Q0 aggregate evidence cannot decide whether a given page-2D fallback, open-row candidacy or router tie occurred in this row. Capture both sides of each conditional with qualified symbols and evidence when active. An observed fallback that matches a predeclared, fully bound branch can be scored against its own native comparison. A novel implementation/path or absent conditional evidence must never turn into a vacuous equality of two missing payloads. Excluding an inactive field requires a recorded guard and reason agreed by the independent scorer before unsealing candidates. Never treat an entire missing row as an inactive path.

## Preserve and resume the original

First record the untouched comparison and the stock instrumented reference to completion; keep the five immutable B/D snapshots off device under bounded private custody. Stage two requires a fresh source process reproduced against the admitted reference. At B₀ fingerprint and compare the live protected graph with the native reference. While the original is paused, seed both linked branches from independent restores. Run private instances serially under an observed single owner, compare source values, object slots, aliases, positions and pending writes before/after each private interval, then resume only the original object graph. At each of the five live Bₖ cuts run the three anchored instances from independent copies; compare source before/after and the source's native B, D and transition to the admitted traces. After emitting the delimiter resume from D₄ to the native terminal in the table. For contiguous private phases verify untouched protected graph before the first and after **each** instance/commit, including graph binding, data bytes, weight/config immutability evidence and ordered stream fences. Fresh processes may run serially with offload only under an explicit plan proving that suspension and resource use preserve the original state. Copying a reconstructed source from the reference after private work would erase evidence of corruption. The originally paused source must actually continue.

Persist canonical bytes with lengths and hashes, phase indices, event ancestry and failure receipts. A strong digest identifies an artifact; it does not reconstruct unknown bytes, prove absence of transient writes or replace checking live read/write disjointness. Compare protected source *within the same pause* against its pre-private graph; compare normal native evolution *between* pauses against corresponding stock states. A page counter changing during native progression is expected; the same update while the source is paused is an isolation failure. If outputs agree while private writes touch protected bytes, record an isolation mismatch even if a later restoration hides it.
