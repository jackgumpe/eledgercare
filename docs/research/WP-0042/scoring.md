# Offline scoring contract and admission

The field decision is made once over a fixed set of obligations. The full denominators below stay fixed when a branch fails early. An implementer must expand the repeated indices before running and obtain independent agreement on the keyed manifest and file encodings. Implementation convenience cannot delete a row, atom or measured mismatch. An extra optional diagnostic cannot supply a missing required field.

## Derive the guards without trusting the observed scores

Use the native vocabulary V={0,…,129279}. Check r, zN (after no-repeat) and z (after page count) have exactly 129280 FP32 elements in native token order. Pin tokenizer and ID ranges. The lengths and domain must be validated before elementwise comparison; truncating to the shorter vector with zip would silently accept missing elements.

Let H consist of all generated IDs through and including the current consumed token x[g], n=|H|. Prompt IDs supply expected_pages by counting page markers, but they are excluded from the n-gram guard. For n≥35, let p=H[n−34:n]; B contains H[i+34] for each integer i from max(0,n−1024) to n−35 inclusive with H[i:i+34]=p. Subtract the whitelist (empty here). For n<35 define B empty. Then A_N=V∖B. Reconstruct the page guard with the saved pre-call dictionary, separately derive its state by replaying the *native order* from empty generated history at the first prediction, and require agreement. For newly scanned H[scanned:n], increase marker_cum by its number of page markers, set page_len to the suffix length after its last marker if there is one, otherwise add its length, and set scanned=n. If there is no new tail all three retain their values.

For the updated marker count m, expected count e, cap c and page_len l, define A_P in priority order:

1. If e≤0, V and no guard update.
2. If m>e, singleton {EOS}.
3. If 0<c≤l, singleton {PAGE} when m<e, else {EOS}.
4. If m<e, V∖{EOS}.
5. Otherwise V.

Use A=A_N∩A_P. The native page guard saves a cloned *already n-gram-processed* entry before masking the vector and restoring that value. A singleton force of an ID banned by the first guard yields an empty allowed set. For example a forced page ID previously set to −∞ remains −∞. The scorer must reject invalidity independently of whether the native argmax returned an integer. Do not derive allowed bits from isfinite(z). For this field, the archived first marker is at generated index 0 and the second is at 1145. Thus at each of the five score calls e=3, m=1, n=g+1, l=g; the page guard bans EOS at all five under the pinned rule. Derive B independently from all archived contextual IDs. Tally _uocr_pg from its own prompt-plus-token history separately; it counts prompt markers as well and updates at model entry.

Check finite h, normalized and residual hidden vectors, u, raw r and valid expert weights/biases; record unexpected non-finites before any native nan_to_num when observed on required hidden/raw fields. For each ID independently, check zN equals r bitwise on A_N and exactly the native negative infinity sentinel off it. Check z equals zN bitwise on A and encoded −∞ on its complement. Every allowed processed value is finite and |A|>0. Validate the actual pre- and post-page states, guard invocation order, selected branch, hard id and observed effective writes. A missing or malformed allowed-set payload cannot be reclassified as an all-forbidden pass. Independently compute complete maximum tie sets and first maximal indices over the flattened r, zN and z. The r and zN winners are diagnostics and can differ from native y. Require y to equal the first global maximum of final z and to belong to A. With raw r=(9,4), allowed set A={1} and final z=(−∞,4), the raw winner is 0 and the correct native y is 1. For singleton A no second-place margin is defined. When a comparison includes a margin, derive it from full observed scores on named rivals, retaining signed-zero bytes. Never assign the vocabulary tie rule to torch.topk in DASH or MoE. Preserve native ordered route/expert selections and weights.

## Independent comparison and first-failure report

Use versioned, length-framed fields. For an array record dtype (including BF16 as stored), byte order, rank, shape, logical row-major axis order and full logical bytes; record native storage order/strides, offset and byte-range map separately. Do not upcast BF16 to FP32, reserialize FP via decimal JSON, or compare allocator pointers between independent processes. Encode scalar type/width and signedness, bool as one byte, unbounded Python integer with sign and length, structured strings as explicit UTF-8 lengths, container types/keys and any semantically relevant ordering. Distinguish null, absent, empty, inactive and unobserved. Validate lengths and metadata before indexing. Use little-endian as the declared canonical scalar serialization with a documented byte-lane transform from native order. Compare exact logical bytes and alias graph, then check semantic validity independently. Matching positive/negative infinities on forbidden positions are not interchangeable. On little-endian FP32, +0→−∞ first differs at byte lane 2, not 0.

The scorer consumes a read-only manifest plus captured bytes in a separate process with no mutation access to the run. Cross-check source/run IDs, declared child count/order, monotonic positions, complete field and byte range, uniqueness, tensor metadata, dimensions, element counts, permitted dtype/domain, integrity digests, missing/present bitmaps and stale/cross-run references. Recompute masks, counters, deterministic readout from the **recorded processed scores**, ties, logical lengths and terminal expectations independently of observer-produced verdict labels. Reconstructing head arithmetic on CPU would answer a different floating-point question. Independently verify append and bridge ancestry with references to actual before/after bytes and call receipts. When two branches return identical bytes, instance identities and fenced restore receipts must still prove independent executions. Verify each reconstructed view against address intersections and each rebind against the object graph, in addition to byte equality.

For an observed invalid value (including wrong anchored path, nonfinite raw, short vector declared complete, impossible shape, contradictory IDs, disallowed duplicate or demonstrably corrupt artifact), record M with the violated condition. For absent/truncated or inaccessible evidence, unavailable path identity, interrupted run or unscheduled-by-failure future item, record U on remaining atoms. A truncated row with known differing prefix is M on the observed conflict and U on missing cells. A transport corruption invalidates the supplied artifact; distinguish that protocol failure from evidence of differing model numerics. Preserve terminal reason, observed failures and missingness separately. Aggregate min(M,U,P) over all required atoms as in the design. Output per-arm scheduled/completed/mismatching/unmeasured counts, five row verdicts, bridge/selection/source/comparator/terminal gate verdicts, and one field verdict. Coverage counts can overlap for mixed partial failures and must name their denominator. At present, zero of five native rows have complete state, zero private calls of 30 and zero matching live continuation pairs have been observed.

Emit first observable discrepancy in causal phase order, preserving simultaneous/ambiguous order as an interval. Record run/arm/k/t, instruction/phase, invariant, logical field path and earliest differing tensor index or object slot, native/candidate typed words, differing byte lane and mapped allocation offsets when licit, predecessor matching cut, branch and stream receipts, plus every other conflict and missing key. Example: B₀ matches, post append differs only in _dash_idx_k[11] object's sequence length 1447 vs expected 1446, while K/V equal. Inspect the cat/rebind and private ancestry before attributing an attention arithmetic defect. If all D₀ bytes agree but B₁ has a differing _dash_dec_allow, inspect the page handler/bridge. If r differs but z and y match, retain the raw mismatch. A source dict rebind with unchanged former tensor bytes is a distinct source failure. If the resumed document's 2558 IDs match but terminal observation is absent, classify the terminal U.

## Admission record to freeze before a device request

* Stage 1 requires exact reviewed observer/scorer and untouched comparator revisions, entry/arguments, executable command, executable and wheel hashes, clean branch, resolved module/line offsets, Q0 model/tokenizer/raster/fixture and complete warmup matrix. Declare whether low-level kernel identities are observable and which numerical backend properties are essential. Use one permitted reference target and one observed target, with matching prehistory counted explicitly (two independent loads and eight document calls if reproducing the four-call prefixes above). If history cannot be reproduced under the authorized inputs, withhold that comparison.
* Bind an explicit local-only, uncommitted per-run output root, per-object manifest, real operator/sole device UUID, start/end and observed occupancy, process lock, approved offline environment, storage/host/GPU ceilings and supervisor conditions. Set numeric ceilings for device allocation and reserve, host commit, wall/load/per-document time, no-progress interval, file count/total bytes/log bytes and free disk. Derive storage from all planned phase/projection counts including both archive and temporary copies; one raw plus one processed five-row FP32 capture alone costs 5×2×129280×4=5171200 bytes, before the intermediate zN, all comparisons and caches. Approval must include the actual ceilings and command; they are not specified or measured by this CPU design. Refuse before load on missing receipts, insufficient free space or competing owner. On overrun, stop only owned work, fence/mark partial artifacts, preserve their hashes, record missing obligations and return the lease. No automatic retry on an altered matrix.
* Freeze data schema, sentinel representation, conditionals, canonical comparator/scorer, completion/equality/validity tests, private/protected storage and output ACLs, bounded write destinations and publication policy. No physical/custodied/private data are needed for this synthetic-field qualification. Keep model tensors, raw snapshots and process pointers private. A public summary can give hashes, paired counts, decision and approved discrepancy metadata.
* Stage 2 needs a separate independently reviewed restore/private runner, source pause-resume candidate, exact stage-1 reference hashes, independent scorer, actual same field and resource admission. Freeze every initial branch and call count, which post-state commits, the source lifetime and serialization/fencing strategy. Test evidence for alias restoration, negative controls, processor membership and prefix/cut mapping must exist before any private native execution. A gap in write-set discovery or an unrepresentable stream/handle blocks cloning. Only the coordinator can release this new stage after stock fidelity.

Public-facing output from these checks may support one of three decisions: source conflict found on this configuration, no decisive evidence yet, or complete qualified parity on the declared field. Accuracy, timing benefits and deployment do not enter this verdict.
