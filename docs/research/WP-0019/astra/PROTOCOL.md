# WP-0019 frozen crop policy and paired run

The input is an admitted ordered family manifest containing only source and raster metadata. The operator passes the current verified Carbon worker directory. The same process performs one excluded full read of the first admitted page, then each timed arm in the specified order. Each arm performs its own full-page recognition on every page. Each order starts a new worker. No result, text, region, identity or prediction from the first arm enters the second arm's selector or merge. The runner checks the second full pass against the first.

AB means full-only followed by full-plus-crops. BA reverses their order. The same command accepts either order. Run orders and families serially. Historical H/A are exposed development and regression data. Score with the original WP-0015 scorer separately after predictions are frozen.

## Selector and merge

1. Run the frozen WP-0015 ruled-grid detector on the source bitmap once per page and arm. Its grayscale thumbnail is used only to locate the rules. All recognitions use original 1×, opaque BGRA8 pixels without edits. Run the frozen full-page layout. Recover word membership by the same projected and rounded word centers. Keep all grid cells including explicit empty strings. A page without a detected grid acquires no table.
2. Enumerate detected cells in table, row and column order. Select any cell containing a digit. Also select every body cell of a column whose first row contains a generic identifier label or whose body contains a digit together with a hyphen or letter. This includes empty cells and ordinary numeric distractors. Cell crops start at the ceiling of the left/top detected rules plus 4 pixels and end at the floor of the right/bottom rules minus 4 pixels. The rectangle is half-open.
3. Then enumerate WinRT lines in raw order, omitting words whose centers were assigned to a grid. Select a nonempty prose group when it has any digit or a generic label such as ID, docket, inspection or reference. The complete generic vocabulary is in policy.py. Crop the union of the group's original pixel boxes with 12 pixels left/right and 8 top/bottom. Clip all regions to the bitmap. An absent line has no candidate. No expected field, character, box, page identity or answer participates.
4. Keep the first eligible nonempty rectangle. Skip subsequent eligible rectangles sharing a full word with a previous selection or overlapping at least half the smaller selected/candidate rectangle. Stop issuing calls at 32 per page, while still emitting the omitted regions and reasons. Each selected region receives one crop call. Write ordered words and boxes in both crop-local and page coordinates. Compare each worker-reported input digest with a fresh independent Pillow slice. Verify the worker's source-rectangle and retained-page digests, dimensions and pixel format.
5. Preserve agreements, empty crop reads and multiline crop readings. Any differing value that fails acceptance retains its full value with an explicit disagreement flag. A sole raw crop word with at least two ASCII alphanumerics on each side of each hyphen and at least one digit can populate a detected empty identifier-column cell. An unobserved region stays missing.
6. For a nonempty group, strip the identical prefix/suffix *words for the comparison only*. Exactly one changed crop word must satisfy the same identifier syntax. If any original changed word was already a valid separated identifier, retain the original. The admissible changes are a crop-supplied delimiter on an otherwise identical alphanumeric word, or a crop-supplied single identifier whose literal characters exactly match two or more full-page fragments. The fragments must be ordered with every horizontal gap between zero and 35% of their median height. The complete full/crop word envelopes must overlap by at least half the larger area. Only a literal raw crop reading can enter the prediction, with its mapped word boxes. No emitted glyph is generated by joining, stripping, rewriting or consulting a key. These rules still risk collapsing a legitimately spaced identifier and may retain an incorrect but plausible full read. The paired scorer measures both risks.
7. Reapply the original layout to the merged word stream. The final scorer reads prose from actual spans and matched grids from table rows. Retained disagreements flag their original spans and cell value when applicable. Accepted changes keep a separate disagreement indicator in evidence. Page text is rebuilt from the layout. All emitted grid values must match the recorded decision, including every unselected empty cell.

## Evidence and clocks

Each arm starts when its ready-input page loop and output directory begin. It ends after the durable prediction is written. Both arms independently open and verify each admitted RGB bitmap and opaque BGRA bytes, run full recognition and layout, and durably write per-page evidence and their complete prediction. The crop arm also includes selection, independent and worker-side pixel checks, crop recognition, merge, layout recomputation and larger evidence writes in that clock. The original Windows write-through publisher flushes file contents and publishes by rename. Warmup and worker startup are separately timed and appear once per order. The second arm reuses that same started worker. Manifest metadata validation, module loading, final receipt output and worker shutdown are outside the arm clocks. The measurement includes this research harness's validation and storage cost.

- Each arm writes prediction.json and page-NNN.json. Each page record has full (the unmodified reader response), full_identity, grids, bitmap metadata and regions. The A arm has no selector or region audit. Its grids and full/raw words are retained.
- A B region has id, kind, grid_index or line_index, bbox_points, rect_px, full_word_refs, full_value, eligible, selected, reason, emitted_value, decision, flagged and disagreement. Each selected region also stores the complete crop response, expected_bgra_sha256, observed_source_sha256, projected_words and crop_value. Prose region IDs refer to raw WinRT lines. Match prose to score positions using actual projected span geometry; their ordinal is not the reference line number. Grid indices and word references are zero-based. Source/field locations in region IDs are one-based.
- receipt.json binds source files, runtime metadata, manifest SHA-256, warmup and both arms' semantic full hashes, elapsed nanoseconds, pages/minute, crop counts, per-page evidence SHA-256, durable prediction SHA-256 and added milliseconds/page. Semantic hashes include pixel identity, dimensions, format, raw text, ordered raw words/boxes and angle. A failing comparison leaves partial output and a failure receipt. Output directory reuse is refused.
- Keep scoring separate. Eligibility, selection, crop agreement, flag, accepted crop and scored transition are distinct. Count all expected critical fields, selected and omitted positions, missing/no-word cases and correctly preserved explicit blanks. Each field score must retain its locator, method and actually emitted string. Stage 2 authorization belongs to the coordinator under the registered gate.

The constructed.py command accepts --out with a fresh scratch directory and checks both orders using synthetic words, geometry, color pixels and an in-process test double. It makes zero Windows OCR calls.
