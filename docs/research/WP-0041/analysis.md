## 1. Transition, indexing and parity

At decoding position t, let x be the token consumed and h0 ∈ R^1280 its causal layer-10 output before the final block's input norm. The scores from this step predict the **following** token. Let S contain the full state influencing this block and let F(h,S;x) return pre-final-norm output and post-state. Suppress fixed image features, weights, attention mask, dtype, positions, kernels and metadata in the notation. Native earlier layers may already have advanced on x when the debugger reaches layer 11. Capture the layer-11 entry cut and the corresponding global/model state at that cut. Do not globally rewind eleven earlier layers or advance the model-level page handler twice.

Evaluate (h1,S1)=F(h0,S;x). Matched L1/P1 reads h1 and commits S1. P2 calls F twice with h0 on independent pre-token copies, requires identical results and commits S1 only once. L2 computes (h2,S2)=F(h1,S;x) from another original pre-token copy, reads h2 and commits S2 only on its isolated field branch. Never feed S1 as the second input state. An extra full decoder-layer invocation includes the attention, residuals, norms and MoE. It precedes the usual final RMSNorm and head. In this notation F includes the block's input norm before its attention.

**Proposition 1.** If a one-token stock decode appends one position to the layer, every private call starts at length t and returns t+1 there. Selecting either private result advances the layer once. Determinism at fixed settings and byte-identical complete inputs imply both P2 results equal P1's result. P1 uses the actual stock computation. Together with equivalent readout, processors and deterministic ties this reproduces the native next ID and post-state. Native prefix parity is the induction base; the identical resulting state and next input give the next induction step, up to and including prediction of the closing delimiter. The conditional proof does not establish device determinism, wrapper fidelity or complete snapshots. L2's state length follows the same invariant but its values may differ.

With 31 earlier positions, private calls each return 32; passing the same mutable state twice can produce length 33, spilling into block two. Removing the last K/V does not restore the router key or a token counter advanced twice. The constructed check starts tok=30, compares one advancement to 31 and a double advance to 32, then trims the toy K/V. An ordinary ID advances the page-local token coordinate. Page markers instead change the page with clamping and reset tok to the saved prefill count. Equality of length or selected ID alone proves neither cache nor byte parity.

If contextual pieces were “1”, “7”, “.00” and a single closing token, the input positions would be the last opening token, “1”, “7” and “.00”; they predict four pieces, thus four extra evaluations. There is no fifth evaluation on the already predicted closing token for that four-piece output. Count each piece of an actual multi-piece closing tag. The free branch may take a different number; include prefix reconstruction, original/altered lengths, early stops, truncations and any shared-position work separately. Preserve the first-pass document outside the isolated field.

## 2. Greedy readout and information

At one matched decision on a common finite allowed set A with |A|≥2, let z1,z2 be actual **post-processor** scores and a the unique first winner. For j≠a let m_j=z1_a−z1_j>0, δ_i=z2_i−z1_i and m=min_j m_j. The exact identity z2_j−z2_a=δ_j−δ_a−m_j proves Proposition 2. Rival j beats a precisely when its relative gain exceeds m_j. Another rival may still beat j. Equality gives a pairwise tie; whether either is emitted depends on every score and the frozen tie order. If |A|=1 only its member can win. Empty, all-masked or nonfinite admissible sets require explicit handling outside the theorem.

If |δ_i|≤ε for each allowed token, then δ_j−δ_a≤2ε. A margin m>2ε retains a uniquely. At equality a rival can tie, but cannot strictly overtake. With scores (2,0) or (0,2) perturbed to (1,1), lowest-ID priority preserves the old winner in the first orientation and changes it in the second. Below threshold, zero perturbation preserves the winner while sufficiently favorable shifts can reverse it. At z1=(1.40,1.00), z2=(1.25,1.30), lead 0.40, δ=(-0.15,+0.30), relative gain 0.45, new rival lead 0.05. The same switch is a recovery with print “7” and a regression with print “1”.

Let u_r be final RMSNorm(h_r). For the ideal fixed linear head with row w_i and fixed bias, raw change equals w_iᵀ(u2−u1). Pairwise raw relative gain is (w_j−w_a)ᵀ(u2−u1), bounded above by ||w_j−w_a||₂ ||u2−u1||₂. Strictly smaller bounds than **each raw lead** protect the raw winner. Collinear aligned differences (3,4),(6,8) attain 50 and show why the strict inequality matters. In finite-precision execution there is also head-rounding error; casting the head's already-computed output to FP32 does not undo it. For a certified numerical geometric bound include corresponding evaluation error or compare the observed finite logits directly. The raw geometric bound does not cover differing allowed sets or processors. A mask can reverse a winner even with identical raw scores. Uniform score bounds are sufficient; direct subtraction is exact on the represented numbers if evaluated with sufficient precision.

Consecutive emissions can agree while future scores diverge. A toy block appends input h to its private history and outputs h+1. At h0=0 the private histories end in 0 vs 1; any threshold readout giving the same token to h1=1 and h2=2 will match now. A future decision sensitive to the stored value can differ. Therefore repeat a matched-state test from the same new native snapshot to attribute a later change to that invocation. Compare evolving branches for the full-field endpoint. If complete encodings, pre-token states and fixed policies coincide for two different prints, deterministic composition gives equal outputs by induction. It cannot correctly resolve both distinct true values. A crop helps only if distinguishing information survives its encoding and the reader uses it.

Independence alone with fixed nonidentical family-specific signs and only averaged equal marginals is insufficient. ## 4. Matched workload cost

Let p∈[0,1] be the probability of one selected field on an incoming page. Let a≥0 ms/page be incremental state overhead averaged over **all** pages; let b,c be conditional mean incremental loop and crop costs in ms/trigger under the same route. Partition time without double-counting. With a common page baseline, linearity of expectation gives E[T_loop−T_crop]=a+p(b−c). No constant per-field cost is assumed. Proposition 3 follows by strict comparison to zero. For c>b the loop is faster iff p>a/(c−b); at equality it breaks even. Threshold ≥1 leaves no feasible strict gain. If c≤b there is no strict saving under a≥0. When p=0 only page overhead is incurred; conditional means need a separate reference or a defined zero product. If the measured relative retention cost can be negative, use the unmodified difference rather than the special-case threshold.

With a=2, b=3 and c=11, threshold 1/4. At p=0.1 the loop adds 1.2 ms/page; at p=0.25 the two tie; at p=0.5 the loop saves 2 ms/page. All numbers are illustrative. Conditional service times need not represent batched throughput or full wall time. A later authorized paired test would compare Stock/matched L1/L2/Crop on the same cells; report family denominators, literal and value accuracy, nine transitions, original and changed token counts, reconstruction/retention/transfer including skipped pages, cold and warm timings, peak memory and end-to-end batch/load. Remote-block overlap alone cannot rule out local attention or inherited image information. Nor does one gain, damage or crop win identify a causal mechanism, prove a need for training, or authorize a physical trial.
