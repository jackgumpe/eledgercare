## Reading and reproducing the evidence

- Use `(packet, at)` to join a location with the paired ledger. Reference ordinals in `at` start at one. `truth_pointer` and all raw line, raw word, span and grid indices start at zero. A location's `raw_file` and `raw_sha256` bind its raw bytes. `page_evidence_key` joins to the page-level record for geometry, grid assembly, original raw line and word order, and page, truth, prediction and window SHA-256s. [H pages](coverage/pages-H.jsonl) · [A pages](coverage/pages-A.jsonl)
- Within the raw file, word indices address `/reader_result/lines/{raw_line}/words/{raw_word}` and line text addresses `/reader_result/lines/{raw_line}/text`. The same word's span index addresses `/spans/{span}` in the saved page. For each span the independent reconstruction reproduces text, projected coordinates and flag exactly. For every page it also reproduces the emitted grid's full rows and the page text from the archived rule lines and ordered raw words. All 88 H and 1,301 A spans match.
- For cell attribution, intersecting raw boxes, raw centers inside the region and reference-eligible words must agree as sets before assigning a raw-text difference. For prose, all geometrically eligible spans must agree with the final reference-line members. The trace checks WinRT order against scorer order. A raw line comparison uses its actual text, or a contiguous cell segment only when the whole raw line verifies the word-to-string alignment. A matching value after removing whitespace identifies character preservation, without recommending that whitespace be removed. [Trace source](trace.py) · [Coverage source](coverage.py)
- `python -B docs/research/WP-0018/words/trace.py INPUTS WITNESS_OUTPUT` regenerates the four-witness JSON. `python -B docs/research/WP-0018/words/coverage.py INPUTS COVERAGE_OUTPUT --checkpoint WITNESS_OUTPUT/witnesses.json` requires its SHA-256 `64b8e29bcacee8d0978e422bfc3f3c6471877a5c2b30eb69104891f7c073c5a8`. Use an admitted private H/A input copy and a checkout with paired evidence commit `01625378954a55da0fe7ce93c5cbb3b2e174c797` available. The packet source bindings use the published inventories for H's `h-r1-ab/04-h-windows` and A's `a-recovery-ab/04-a-windows`.
- The coverage program checks each original cell and line against the complete saved scorer detail and each cell against the separately authored paired ledger. It verifies 320 keys, references, original selected grid pointers, fallback span order, matching IoUs, outcomes, values, flags and bindings. The paired author ran the complete scorer in separate processes. The word tracer uses the pinned scorer's per-page layout function to verify archived memberships.

**Recommendation.** Prioritize a bounded recognition-input test on the anchored character mismatches, with the H p2 correct prose ID as a control. Track native word splits separately. Keep the empty-string/null distinction as a separate scorer test. For the five absent groups, the smallest additional observation is a localized inspection of the original image content and neighboring boxes, followed by a controlled comparison only if separately released. This archive-only result does not measure customer accuracy or identify which recognition mechanism to change.
