# WP-0035 comparison interface

Each role publishes four comparison files under its own WP-0035/evidence path. Each file contains a JSON array, UTF-8, named scores.json, contrasts.json, terminals.json, custody.json. A .gz suffix with the same decompressed JSON is allowed. Other evidence files may be implementation-specific. Use actual JSON numbers (Python float native binary64 round-trip), booleans, null and lower-case hex, no rounding, NaN or Infinity. Additional keys allowed. DO NOT infer unobserved values. Model IDs M1/M3/M2. W0/W1/W2a/W2b; M3 damped is W1. R0/R1. Symbolic uses write=read="symbolic". A and B are separate task tags. Pair and binder are opaque IDs from matched fixture manifest (A) or public cal by_pair (B). Horizon is 12 or 30. Canonical axis always Alder minus Cedar, c1 true for Alder member. Use the historical public expected values; never derive membership from list order.

1. scores.json. One row per member per readout with task,pair,binder,horizon,model,write,read,phase,step,score_hex,top,gap,score_pass,gap_pass. Phase and integer step for Task A match WP-0030 exactly ("initial","post","native_pre", and archive step including post-target). Hex is two little-endian FP32 logits in Alder/Cedar order, top is unrounded top score promoted, gap is difference of the top two scores after promotion to binary64, gates use native FP32 comparison and FP32 subtraction, threshold >=. If comparing a larger directory separately show actual leaders and full-directory gap. For B record the actual eligible terminal scores only ("native_pre", step = -1 for this comparison file; preserve actual pointer and step in evidence). No synthetic score rows on missing/no-target. For A include scores on all retrospective fixed-directory reads incl zero; separately preserve actual registry eligibility and controller/target availability.
2. contrasts.json. One row per paired scoring point with task,pair,horizon,model,write,read,phase,step,alpha,beta,delta,mu,gamma,wins. alpha/beta are the two Alder-minus-Cedar member margins, signed, computed after FP32 promotions. delta=alpha-beta, mu=(alpha+beta)/2, gamma=delta-2*abs(mu), wins=int(alpha>0)+int(beta<0). Keys and coverage match scores. Strict ties give zero for that member. Retain checkpoint labels, observed pointer, depth, W designation, raw anchor diagnostics, effective alpha/rho/beta and candidate identities in these or other owned evidence. Supply measurements supporting or qualifying the hypotheses, including actual attenuation interval, root write counts and treatment contrasts.
3. terminals.json. One row per actual binder/arm, incl ambiguous safety and M2, with task,pair,binder,horizon,model,write,read,typed. typed is the native-shaped complete Posting or Abstain dictionary (preserve exact reason) under R0 or scoped owner-score replacement for R1. Also supply expected/answerability, full-typed correctness, owner-only gates/wrong decisions and all denominators in this or other evidence. M2 has no neural scores, owner cutoffs or neural rank. Task A typed at actual target; for Task B preserve actual no/multiple-target native decisions.
4. custody.json. One row per exposed calibration pair including the two safety pairs, fields pair,horizon,tier (integer 1/2/3),answerable (boolean),members. members maps binder ID to an ordered list per window of [receipt_sha256,metadata_sha256,pooled_sha256] as stored in the authenticated public archive (hash exact archived bytes). Preserve tag/path, archive revision/digests and other bindings in this or separate evidence. Report missing inputs and identifiers if any—do not label full stream missing solely because no target event occurs.

Separate parity evidence for all 224 native paired points and full 4-cell W1 controls, including exact scores, digests and state where exposed. Full metric tables/calibration and safety breakdown are independently required. Coordination compares all common rows by identity and field, not file ordering. Execute source-only preparation concurrently, decisive computation exclusively on the root-released candidate.
