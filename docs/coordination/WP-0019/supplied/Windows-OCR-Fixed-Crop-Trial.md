## Freeze the comparison

1. **Post-update control.** Record the Windows build, WinRT OCR language and exposed engine/package version, recognizer settings, adapter revision, scorer digest, and actual dimensions and pixel format received by the recognizer. Mark unavailable fields unknown. Run the unmodified full-page reader on the historical witness pages. Retain both the old and new observations if they differ. Use the same-installation control for every treatment comparison; if paired input or runtime identity cannot be established, stop that comparison. Do not silently substitute old Windows predictions.
2. **One treatment.** Both arms start with the same full-page pass. The treatment may additionally call the same recognizer once for each eligible region: a fixed-padding integer crop copied from the exact full-page input bitmap. Same pixels per glyph, orientation, pixel format and language; no scaling, thresholding, deskew, border removal, training, or character rewriting. Hash the full-page input and crop bytes; verify the crop against its source rectangle and map returned boxes back to page coordinates. Check that neither arm silently rescales its input. Any required conversion must be identical before cropping.
3. **Choose before scoring.** On development pages, specify one deterministic selector for identifier-bearing lines/cells using information available to the application (such as a detected grid or raw word geometry), the padding, clipping, duplicate/overlap behavior, and maximum number of crops per page. Freeze the rule for using a crop's returned text versus keeping the original, including empty reads and no selected region. No answer-key boxes, expected strings, page-specific repairs, or choosing whichever arm was correct afterward. A separate descriptive count may show when the crop contained the right answer but the frozen rule did not use it. Never count that as an end-to-end recovery.

## Run in two stages

**Development/regression only:** H p2 table 1 r2c1 (`1L8O1-493`), A p60 table 1 r2c2 (`0I8O1-139`), H p1 line 2 (the split `88L1L-631`), and the correctly read H p2 line 2 (`880LO-977`). Capture original and crop WinRT line text, ordered words, boxes and final emitted value. Preserve the five no-word A cases as a separate stratum: a region the selector cannot find remains in the denominator. Do not hand-find it using truth. These known examples can diagnose behavior, not establish generalization.

**Fresh check:** Before execution, an uninvolved custodian fixes two new synthetic form families, six pages each, and commits to raster and answer-key digests separately. Include table and prose IDs, confusable and ordinary characters, single and legitimately spaced values, blanks and negative controls. Record counts and fixture provenance. Keep fresh pixels and labels out of selector tuning; keep labels from both arms until candidate predictions and run receipts are frozen. Do not reuse H/A or open sealed Packet B. Use the same frozen candidate on every fresh page; no tuning or retries in response to revealed results. Pair and counterbalance arm order (AB/BA) under matching warm conditions; disclose startup separately. Repeats are timing or reproducibility checks, not additional unique examples.

## Score and decide

| Measure | Required evidence |
| --- | --- |
| Exact critical IDs | By family, report control and treatment correct/total, wrong→right, right→wrong, wrong→wrong and right→right with page/field locators. Use *all* expected IDs for the main comparison, including unselected ones. Report attempted crops, missed regions and outcomes among selected IDs separately. Count newly wrong and newly **unflagged** critical values separately; flagging is not correction. |
| Failure mechanism | Distinguish wrong characters, whitespace-only word splits/merges, mixed damage, and no returned word. A joined string used to classify an error is not a corrected production value. Check legitimate spaces and preserve correctly empty cells; do not convert missing evidence into an empty value. |
| Time | Measure the whole control and treatment on the same host, from the same ready-input boundary to durable prediction. Include region selection, cropping, second recognition, merging and writing. Report elapsed seconds, pages/minute, added ms/page and crops/page. Use all pages, including pages without crops. A short-fixture rate is not a demonstrated 60-page service rate. |
| Reproduction | Freeze trial code and raw outputs. Have a non-author reproduce the paired checks and decisive readings, verify geometry and field-level transitions, confirm the baseline and original archive remain intact, and report unavailable or nonreproducible cases explicitly. |

**Decision rule to register before unblinding:** Recommend a larger *research* trial only if the frozen end-to-end policy recovers at least one fresh critical ID, yields no newly wrong critical ID across the fresh fixtures, preserves blank handling, and meets the project's 30 pages/minute target on the fresh run. Show each family's counts even if gains appear in only one. Zero gains or a regression is a useful result; distinguish a failed criterion from an inconclusive run (e.g., the fresh baseline made no errors or custody failed). No outcome from this small lane approves unattended use. Report an informative crop reading even if it fails the selection, timing or regression criterion.
