The worktree-relative Python interface is `docs/research/WP-0019/carbon/engine.py`. `with Worker() as worker` starts a single en-US WinRT process. `worker.info` is a dict. `worker.full(bmp_path)` recognizes the complete BMP and retains the current full bitmap. `worker.crop([left,top,right,bottom])` uses a half-open integer rectangle on the retained page. Both return `text, lines[{text,words[{text,bbox}]}], width, height, bgra_sha256, pixel_format`, with word boxes in their input's pixel coordinates. Crops expose the source-rectangle hash and full input hash and prove byte equality before recognition. The caller verifies hashes/dimensions/format against the admitted page and independently sliced bytes. One full-page lossless BMP per page is admitted in advance. Crops stay in memory. No resizing, pixel changes, border erasure, manual ID repair or key-derived selection.
