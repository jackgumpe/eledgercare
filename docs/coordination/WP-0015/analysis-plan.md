# Matched trial decision rules

Freeze this analysis before the first timed challenger. The unit is a previously unprocessed PDF in a ready research service. A second invocation for a noise or direction check must regenerate all outputs from its source. Each run writes to a new empty directory. Retain each accepted-input and durable-final-write timestamp, plus source-page, ordered window, output and stop evidence. A write is durable here only after payload flush/sync and publication of the final manifest. Publish the implementation's exact boundary. A failed or truncated document has elapsed time and a reason, but no complete-document pages/min. A legitimately empty source page still needs its own correctly linked page record.

Measure the control and each selected candidate on the same PDF and renderer. A provider-specific resize required by a candidate belongs inside that candidate's clock and must be disclosed. Warm each active engine on an excluded synthetic input before timed documents. Count all such warm-ups in model usage. Record process start, initialization and first warm-up separately. Alternate treatment/control order across two newly prepared processes for the decisive comparison. Use deterministic target parameters for native BF16 and disclose stochastic or geometry differences. Other active desktop work, file cache state and device clocks are uncontrolled.

For each packet, report raw seconds, pages/min for complete runs, independently tallied quality and source failures. Identify (a) fastest complete and (b) fastest complete within the declared quality budget, explicitly handling missing outputs. Report absolute CER and cell accuracy for both, their changes, and by-page failure counts. Expected printed text, including numbers and punctuation, enters the common scorer. Tables are scored at physical positions or against source-anchored spans as described in the custodian's frozen protocol. Zero applicable cells yield N/A. Evaluate unflagged critical amounts/identifiers and wrong-source links separately. Compare the identities of errors to identify new errors even if total counts match.

For a repeated decisive pair, measure noise as the absolute repeat-to-repeat spread for the same baseline on the same input. Require improvement in both orderings, with each saving larger than that observed baseline spread, then require the uninvolved reviewer's held-out effect to have the same sign and to exceed its own observed control noise when repeated. Record single-observation comparisons as such. No population percentile or general speed guarantee follows from these trials. Changed output may gain at most 0.01 absolute CER and lose at most 0.02 absolute table-cell accuracy against its matched control. Any new or existing unflagged critical error or wrong-source link precludes an unattended claim. An exact-output contender must also preserve every token, stop, physical page and boundary state.

For the 60-page scale decision, estimate the cost from new observed ready-control runs and the custodian's page-class counts without examining reserved answers. Record remaining measured GPU budget and decide before opening a reserved family. If a control and selected candidate cannot finish within the authorized budget, prioritize the representative held-out replay, record the unrun comparison and its estimated cost. Product admission, search, actual last-page transaction commit, and a second unseen family are separate conditions for a demonstration claim.
