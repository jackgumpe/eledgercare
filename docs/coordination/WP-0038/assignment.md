Return a JSON-compatible dict with exactly these keys:
- status: ADMITTED or OUT_OF_DOMAIN_TRUSTED_OPENING. anchor_status: OCR_READ, VERIFIED or CONFLICT. solve_skipped: boolean.
- rho: list of signed integers; D: signed integer. Both null on pre-solve anchor rejection. Check consistency before residual computation and support solving. On rejection clean=false, finite=[], families=[]; zero repairs. No candidate is silently applied, even on a singleton set.
- clean: true iff the empty-support solution exists. finite: list of nonempty finite hypotheses, each an array of [cell,signed_error] pairs in A1..An,B0..Bn,T order (omit B0 in trusted). Sort hypotheses by cardinality then by coordinate-index tuple. No zero-valued coordinates, duplicates or implicit winner.
- families: canonical OCR one-row B0,B1 family only when D=0. Return [{"support":["B0","B1"],"parameter":"c","domain":"Z","offset":[-r,0],"slope":[1,1],"excluded":sorted(unique([0,r]))}].
